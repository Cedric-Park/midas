# ID 생성 정책

## 회원 ID (members 테이블)
- 형식: 7자리 문자열
- 구성: 알파벳 대문자(A-Z)와 숫자(0-9) 조합
- 예시: E39EVMX, ZZD5FRO, ZYUVYPN
- 특징:
  - 고유성 보장 (중복 불가)
  - 랜덤 생성
  - 대소문자 구분 없음

## 예약 ID (appointments 테이블)
- 형식: app_YYYYMMDD_XXXXX
- 구성: 
  - 접두어: 'app_'
  - 날짜: YYYYMMDD 형식
  - 구분자: '_'
  - 일련번호: 5자리 숫자
- 예시: app_20240315_00001
- 특징:
  - 날짜별로 순차적 증가
  - 고유성 보장

## 관리 내역 ID (sessionHistory 테이블)
- 형식: YYYYMMDDHHMMSS
- 구성: 타임스탬프 기반
- 예시: 20240315143022
- 특징:
  - 시간 순서대로 정렬 가능
  - 고유성 보장

## 주의사항
1. ID 생성 시 반드시 중복 체크 필요
2. 기존 ID 형식 변경 시 마이그레이션 계획 수립 필요
3. ID 생성 로직 변경 시 이 문서 업데이트 필요
